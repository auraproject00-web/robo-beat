# Robo Beat

Game lari tanpa henti berbasis HTML5 Canvas. Lompati kardus dan drum oli, nunduk untuk menghindari gagak, dengan siklus siang–malam dan efek suara.

## Cara main
- **Lompat:** tap arena / tombol Lompat / Spasi / ↑ (tahan lebih lama = lompatan lebih tinggi)
- **Nunduk:** tahan tombol Nunduk / ↓
- **Suara:** tombol Suara / M
- **Karakter:** pilih Beat, Nova, Rust, Glo, atau Zee lewat tombol Karakter

Semua dalam satu file `index.html`, tanpa build. Buka langsung di browser atau hosting di GitHub Pages.
