# Robo Beat

Game lari tanpa henti berbasis HTML5 Canvas, layar penuh. Pilih karakter di menu awal, lompati kardus dan drum oli, nunduk untuk menghindari gagak. Ada siklus siang–malam dan efek suara.

## Karakter
Beat, Nova, Rust, Glo, Zee, dan Dino.

## Cara main
- **Mulai:** pilih karakter di menu, lalu tekan MULAI / Spasi
- **Lompat:** tap layar / tombol Lompat / Spasi / ↑ (tahan lebih lama = lompatan lebih tinggi)
- **Nunduk:** tahan tombol Nunduk / ↓
- **Jeda:** tombol jeda di pojok kiri atas / P / Esc
- **Suara:** tombol Suara / M

Semua dalam satu file `index.html`, tanpa build.
